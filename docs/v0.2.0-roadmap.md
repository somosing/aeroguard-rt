# AeroGuard-RT v0.2.0 Roadmap

## Runtime Assurance Watchdog

The next milestone moves AeroGuard from telemetry observation toward explicit high-level runtime-assurance decisions.

Planned scope:

- combine connection state and GNSS health into a watchdog decision,
- keep decision logic deterministic and unit-testable,
- distinguish nominal, degraded, and unsafe operating conditions,
- log every watchdog decision transition,
- measure detection and policy-response timing,
- validate behavior in PX4 SITL before any real vehicle testing.

PX4 remains responsible for stabilization, actuator control, and native flight failsafes.

Initial v0.2.0 work will compute and log decisions only. It will not directly command the aircraft.
